## How to Use

1. **Open any `.html` file in your browser** (double-click or right-click → Open with Chrome/Edge)
2. **Take screenshots** using:
   - Windows: `Win + Shift + S` (Snipping Tool)
   - Mac: `Cmd + Shift + 4`
   - Browser: Right-click → "Capture screenshot" (in DevTools)
3. **Insert into your .docx** as images
