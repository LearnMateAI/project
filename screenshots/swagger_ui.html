LearnMate API

Upload a PDF, ask it questions, generate study material from it.

🔐 /api/auth - Authentication

POST /api/auth/register Register new user
POST /api/auth/login Login
GET /api/auth/me Get current user

📄 /api/documents - Document Management

POST /api/documents/upload Upload PDF (multipart/form-data)
GET /api/documents List user documents
GET /api/documents/{id} Get document details
GET /api/documents/{id}/file Download original PDF
GET /api/documents/{id}/pages Get cleaned page text

🧠 /api/resources - Resource Generation

POST /api/resources/generate Generate resource (async, returns 202)
GET /api/resources List resources
GET /api/resources/{id} Get resource details

💬 /api/chat - Chat Sessions

POST /api/chat/sessions Create chat session
GET /api/chat/sessions List chat sessions
POST /api/chat/sessions/{id}/messages Send message (async)

⚙️ /api/jobs - Job Tracking

GET /api/jobs List jobs
GET /api/jobs/{id} Get job status & progress

📊 /api/analytics - User Analytics

GET /api/analytics Get user analytics

🏥 /api/health - Health Check
